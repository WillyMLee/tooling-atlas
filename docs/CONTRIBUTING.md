# Contributing

Contributions should make a relationship easier to understand across multiple sites.

## A module needs

- a clear reader question;
- semantic static HTML;
- responsive recomposition;
- light and dark theme variables;
- a copyable example;
- accessibility notes;
- a documented maximum content density.

## A website-pattern note needs

- an observed problem;
- the reusable structural idea;
- a known failure mode;
- an original implementation or explanation;
- no private source code or sensitive application data.

## Naming

Name modules for the relationship they express—`flow`, `system-map`, `metric-bridge`—rather than the product where they first appeared.

# Sources

- [Context Mode repository](https://github.com/mksglu/context-mode) — optional local MCP approach for sandboxing and reducing large tool outputs before they enter model context.
- [OpenAI Agent Skills guide](https://developers.openai.com/api/docs/guides/tools-skills) — skills as reusable, versioned bundles of instructions and resources.
- [Anthropic context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) — just-in-time retrieval, clear tool surfaces, and context treated as a finite resource.

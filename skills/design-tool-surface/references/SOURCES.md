# Sources

- [Anthropic: effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) — emphasizes clear, non-overlapping tools, descriptive parameters, token-efficient returns, and just-in-time context.
- [OpenAI model guidance](https://developers.openai.com/api/docs/guides/latest-model) — recommends exposing only relevant tools, using concise descriptions, defining return shapes and errors, and routing programmatic work by task shape.

Validate tool changes on representative tasks. Smaller tool sets and outputs are improvements only when task success and required evidence remain intact.
